# Data Set Definition

## Overview
This project utilizes 3D volumetric data files in the NRRD (Nearly Raw Raster Data) format for processing and projection[cite: 1].

## Primary Data Source
The primary dataset for development and testing is sourced from the open-source **3D Slicer** project[cite: 1]. 
Specifically, the application uses standard MRI NRRD files, such as the recommended sample dataset, to validate the plane projection algorithm[cite: 1].
