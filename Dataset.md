# Data Set Definition

## Overview
This project utilizes 3D volumetric data files in the NRRD (Nearly Raw Raster Data) format for processing and projection.

## Primary Data Source
The primary dataset for development and testing is sourced from the open-source **3D Slicer** project. 
Specifically, the application uses standard MRI NRRD files, such as the recommended sample dataset, to validate the plane projection algorithm.
